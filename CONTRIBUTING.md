# Contributing

Thank you for wanting to help!

- **Bugs and ideas** — open an [issue](https://github.com/PopaSpinka/PopkaStudio/issues): what you did, what you
  expected, what happened; a screenshot or the Load log helps a lot.
- **Your board** — if you'd like PopkaStudio to support another ESP32 board, open an issue with its name and a link,
  or write to lastmail.sk@gmail.com.
- **Pull requests with code** — not accepted for now. PopkaStudio is licensed both for free noncommercial use and
  commercially (see [COMMERCIAL.md](COMMERCIAL.md)); outside code would need a contributor agreement, which is not
  set up yet. Ideas described in an issue are very welcome — they may well end up in the next version.
